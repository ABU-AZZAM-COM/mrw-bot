# 🛡️ لوحة الإدارة لسطح المكتب

تطبيق سطح المكتب (PySide6) للتحكم الكامل بنظام بلاغات المخالفات العسكرية عبر
واجهة Admin API المحمية على المساحة السحابية.

## التشغيل

```bat
:: 1) (مرة واحدة) بيئة بايثون ثم تثبيت المتطلبات داخل مجلد المشروع
python -m venv .venv
.venv\Scripts\pip install -r desktop_panel\requirements.txt

:: 2) (كل مرة) شغّل اللوحة بنقرة مزدوجة أو بالأمر
run_panel.bat
```

- عند أول تشغيل تظهر نافذة إعداد: يُعبَّأ سلفاً رابط المساحة والتوكن الإداري
  إن وجد في `data\admin_panel_token.txt` — عدّله واضغط «اتصال».
- بعد أول اتصال ناجح تتأكد الإعدادات في `desktop_panel\panel_config.json`
  (ملف **سرّي ومهمل** من Git — لا ترفعه لأي مكان).

## ماذا تحتوي؟

| القسم | الوظيفة |
|---|---|
| 📊 «النظرة العامة» | إحصاءات لجميع الحالات تلقائياً كل 6 ثوانٍ + تنبيه صوتي عند بلاغ جديد + مؤشر جاهزية البوت والإيقاف الطارئ |
| 🗂️ البلاغات | بحث متقدم (رقم/اسم/وصف/رابط/معرف) + فلترة بالحالة والتصنيف + ترقيم صفحات |
| 🔍 تفصيل البلاغ | صورة البلاغ من تلغرام + المتبلّغ والوقت والرابط والوصف |
| ⚡ الإجراءات | تغيير الحالة (سبب الرفض **إلزامي** ويُرسل للمتبلّغ) — تصنيف نوع المخالفة — ملاحظة إدارية داخلية — **رد الجهة** للمتبلّغ — حذف نهائي بتأكيد كتابي للرقم التسلسلي |
| 👥 المتبلّغون | قائمة مجمعة (البلاغات/الحالة/آخر ظهور) + بحث + بطاقة كاملة بكل بلاغاته |
| ⛔ الحجب | دائم أو مؤقت بساعات + سبب موثق (يُبلّغ المستخدم) + رفع الحجب |
| 🧾 سجل التدقيق | مين فعل إيه وإمتى — القراءة فقط |

## الأمان

- التوكن الإداري لا يُحفظ في المستودع، ويُرسل في بريد `X-Admin-Token` فقط.
- كل عملية تنفّذها اللوحة تُسجل في سجل التدقيق على السحابة باسم «لوحة الإدارة».
- لو انتهت صلاحية التوكن أو بالعت السبيس أثناء إعادة البناء: تظهر رسالة
  انقطاع، واللوحة تعيد المحاولة تلقائياً كل 6 ثوانٍ.

## حزم ملف تنفيذي (اختياري)

لإخراج ملف EXE واحد:

```bat
.venv\Scripts\pip install pyinstaller
.venv\Scripts\pyinstaller --onefile --windowed --name AdminPanel desktop_panel\panel.py
```

المخرجات في `dist\AdminPanel.exe`.
