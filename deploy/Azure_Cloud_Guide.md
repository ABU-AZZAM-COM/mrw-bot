# ☁️ دليل النشر على Microsoft Azure (البديل عن Oracle)

> **لماذا Azure؟** Oracle يرفض الوصول من بعض الشبكات/الدول بحجة "Export laws" (فحص امتثال تصدير
> يعتمد على IP)./Azure لا يفرض هذا القيد على المستخدمين في السعودية، ويوفّر:
> - **حساب مجاني**: رصيد 200$ + خدمات مجانية 12 شهرًا (خادم `Standard_B1s` صغير + قرص 64GB).
> - **منطقة سعودية**: `sa-central` (الرياض) أو `sa-central-2` — قريبة منك وبزمن استجابة ممتاز.
> - **بوابة عربية** وواجهة سهلة.
>
> ✅ **حزمة النشر نفسها (`install.sh`) تعمل على Azure بدون أي تعديل** — هي مصممة لأي خادم Ubuntu.

---

## المرحلة 1 — إنشاء الحساب المجاني

1. افتح: `https://azure.microsoft.com/free/` ← **Start free**
2. أدخل بريدك (يُنصح بحساب Outlook/Hotmail منفصل للعمل).
3. **التحقق بالبطاقة**: تُقبل بطاقات Visa/Mastercard (ائتمانية أو مدى إن كانت مفعّلة للتجارة الإلكترونية).
   - ℹ️ إذا رفضت البطاقة: جرّب بطاقة أخرى أو **تطبيق الجوال (الإنترنت المحمول)** كشبكة بديلة.
4. التحقق للهوية: رقم هاتف + عنوان (لإرسال الفاتورة) — يُطلب رمز على الجوال.
5. بعد التفعيل: رصيد **200$** لمدة 30 يومًا + **خدمات مجانية 12 شهرًا**.

> 💡 **ضبط مهم لتفادي أي فاتورة**: بعد التسجيل →
> `Cost Management + Billing` ← `Cost Management` ← `Budgets` ← أنشئ ميزانية بمبلغ **1$** مع تنبيه.
> كذلك لن يتجاوز إنفاقك رصيد 200$ أبدًا.

## المرحلة 2 — إنشاء الخادم (VM)

من `portal.azure.com` ← **Virtual machines** ← **Create** ← **Virtual machine**:

| الحقل | القيمة |
|---|---|
| Subscription | اشتراكك المجاني (Free) |
| Resource group | `mrw-bot-rg` (أو `rg-mrw`) |
| Region | **`sa-central`** (الرياض) أو `sa-central-2` |
| Image | `Ubuntu Server 24.04 LTS` (أو `22.04 LTS`) |
| Size | **`Standard_B1s`** ← ضمن المجاني 12 شهرًا (1 vCPU / 1GB) — يكفي للبوت بوضوح |
| Authentication | **SSH public key** ← `Create new resource` باسم `mrw-key` ← ثم **Download private key** (ملف `.pem`) |
| Public IP | `Create new` ← تأكد أن نوعه **Standard** (وليس Basic) |
| Inbound port rule | **SSH (22)** ← المصدر: `Any` مؤقتًا، ويُفضَّل `My IP` لاحقًا |

> ⚠️ **اختيار Region مهم**: إذا لم تجد `Standard_B1s` متاحًا في `sa-central`، جرّب `sa-central-2`
> أو `me-central` (الدوحة) أو `uae-north`. **البنية المجانية 12 شهرًا مرتبطة بالمنطقة التي اخترتها عند التسجيل.**

## المرحلة 3 — النشر (نفس الأوامر على أي مزوّد)

```powershell
ssh -i "$HOME\Downloads\mrw-key.pem" azureuser@<IP_الخادم>
cd /tmp
# ارفع المشروع من ويندوز (نفس سكربت المشروع):
```

من جهازك في ويندوز:

```powershell
cd "<مسار المشروع>"
.\deploy\deploy_from_windows.ps1 -ServerIP <IP_الخادم> -KeyPath "$HOME\Downloads\mrw-key.pem" -RemoteUser azureuser
```

ثم على الخادم:

```bash
cd /opt/mrw-bot
nano .env          # BOT_TOKEN=... | ADMIN_IDS=1557513643 | LOCAL_UTC_OFFSET=3
sudo systemctl restart mrw-bot
systemctl status mrw-bot
```

## المرحلة 4 — التحقق

```bash
systemctl status mrw-bot       # active (running)
journalctl -u mrw-bot -f       # السجلات المباشرة
```

**اختبار حقيقي:** أرسل `/start` للبوت `@blgh_bot` من حسابك، ثم صورة + رابط + وصف ← يجب أن يصل إشعار فورًا.

> ⚠️ **أوقف نسخة البوت على ويندوز** قبل التشغيل على الخادم (تعارض `409 Conflict`):
> ```powershell
> Get-CimInstance Win32_Process -Filter "Name='python.exe'" | Where-Object { $_.CommandLine -like "*main.py*" } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
> ```

## 🔐 ملاحظات أمنية

| البند | الإجراء |
|---|---|
| SSH مفتوح للعالم | بعد التأكد من الاتصال، غيّر المصدر إلى `My IP` من بوابة Azure |
| مفتاح SSH | احتفظ به على جهازك فقط — لا يُرفع إلى الخادم ولا يُشارك |
| الأسرار | ملف `.env` بصلاحية 600 داخل `/opt/mrw-bot` |
| جلسة حسابك الشخصي | **لا تُرفع** إلى الخادم (سكربت النشر يستثنيها عمدًا) |
| البيانات | احرص على بقاء نسخة من الأدلة على جهاز القسم الداخلي — سحابة الطرف الثالث ليست بديلًا عن الأرشيف الداخلي |

## 📌 بعد 12 شهرًا (انتهاء الفترة المجانية)

عند انتهاء الاشتراك المجاني يتحول الخادم إلى **مدفوع** (نحو 8-12$ شهريًا لنوع B1s مع قرص).
خياراتك حينها:
1. تفعيل "الخدمات المجانية دائمًا" — بعض الموارد تبقى مجانية دائمًا.
2. ترحيل المشروع إلى خادم آخر (حزمة النشر محايدة — تنقل بأمر واحد).
3. شراء رصيد أو تسوية التكلفة مع القسم.

## 🔁 بدائل أخرى إن تعذّر Azure أيضًا

| المزوّد | ما يقدّمه | ملاحظة |
|---|---|---|
| **Google Cloud** | `e2-micro` مجاني دائمًا في `us-west1`/`us-central1`/`us-east1` | يحتاج بطاقة Visa/Mastercard؛ المناطق المجانية ثابتة ثابتة |
| **AWS** | `t3.micro` مجاني 12 شهرًا + 750 ساعة/شهر | أقرب منطقة: `me-south-1` (البحرين) |
| **VPS مدفوع** | من 4$ شهريًا (DigitalOcean / Vultr / Contabo / Hetzner) | **الأكثر موثوقية** — لا قيود تصدير ولا تحقق بطاقة معقّد |
| **خادم داخلي** | جهاز القسم أو خادم نظم المعلومات | الأنسب للسرية — ولا علاقة له بالإنترنت |

> 🎯 **نصيحة مهنية:** بما أن الأداة رسمية وتخدم عملًا عسكريًا، استشر **مكتب نظم المعلومات في القسم**
> قبل اعتماد أي استضافة خارجية، فقد تكون لديك جهة تملك موارد سحابية معتمدة داخليًا.
