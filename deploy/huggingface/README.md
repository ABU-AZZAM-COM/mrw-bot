# 🛡️ نظام بلاغات المخالفات العسكرية

بوت تيليغرام لاستقبال بلاغات رصد المخالفات العسكرية، يعمل **24/7 على استضافة مجانية دائمة**.

## ما يقوم به البوت
- استقبال **صورة توثيقية** + **رابط المنشور** + **وصف موجز** من كل مبلِّغ.
- توليد **رقم تسلسلي** مرجعي لكل بلاغ (مثل `MRV-2026-0001`).
- حفظ البلاغات في قاعدة بيانات SQLite مع الحالات: جديد / قيد المراجعة / معتمد / مرفوض.
- لوحة مشرف محمية: عرض، تصفية، تغيير الحالة، وتصدير Excel ونصي.
- نشر كل بلاغ في **القناة الرسمية الموحّدة** + رفع نسخة احتياطية من قاعدة البيانات داخلها
  (مخزن استمرارية مجاني يحمي البيانات من فقدان القرص في السحابة).

## هذه المساحة
هذه صفحة حالة فقط — البوت يعمل في الخلفية ويستقبل البلاغات عبر تلغرام.

## المتغيرات المطلوبة (Secrets)
تُضبط من صفحة المساحة ← **Settings** ← **Variables and Secrets**:
`BOT_TOKEN`، `ADMIN_IDS`، `ARCHIVE_CHAT_ID`، `SAVE_MEDIA_LOCALLY=0`،
`KEEPALIVE_URL`، `KEEPALIVE_INTERVAL_SEC=300`، `BACKUP_INTERVAL_MIN=30`، `LOCAL_UTC_OFFSET=3`.

> تفاصيل التشغيل الكاملة في ملف `deploy/HuggingFace_Guide.md` داخل المشروع.
