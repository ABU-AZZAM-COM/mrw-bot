# دليل النشر المجاني الدائم — Zeabur (Free Plan)

هذا الدليل يشرح خطوة بخطوة كيف يُشغَّل البوت **24/7 على استضافة مجانية 100% ودائمة**
دون حاسوب يبقى متصلًا بالإنترنت، و**دون بطاقة بنكية**.

---

## 0) الفكرة باختصار

| العنصر | الاختيار | السبب |
|---|---|---|
| الاستضافة | **Zeabur — Free Plan ($0/شهر)** | مجاني للأبد، **بلا بطاقة بنكية** (نصّ Zeabur الرسمي: "No credit card required")، ويدعم Python و Docker |
| الكود | مستودع **GitHub خاص** | يبقى الكود غير مرئي للعموم، وZeabur يبني وينشر تلقائيًا عند كل تحديث |
| حفظ البيانات | **قناة تلغرام خاصة** | تلغرام لا يفقد الملفات → بديل مجاني عن القرص الدائم (والقرص في Zeabur مؤقت) |
| قاعدة البيانات | SQLite داخل البوت | خفيفة، وتُرفع نسخة منها داخل القناة وتُستعاد عند كل إقلاع |

> **ملاحظة مهمة عن النوم التلقائي (Auto-sleep):** الخدمات في الخطة المجانية تنام بعد خمول.
> لكن بوت تلغرام لا يوقظه أحد عبر المتصفح، لذلك أضفنا **نبضة إبقاء ذاتية**: كل 5 دقائق
> يرسل البوت طلبًا HTTP صغيرًا إلى رابطه العام على Zeabur، فيبقى الخدمة حيًّا بلا انقطاع.
> وحتى لو نام للحظة: **البلاغات لا تضيع** — يبقى في طابور تلغرام (24 ساعة) ويُسلَّم فور الاستيقاظ.

---

## 1) المتطلبات

- حساب **Zeabur** مجاني (بدون بطاقة): <https://zeabur.com>
- حساب **GitHub** (لنشر الكود): <https://github.com/join>
- حساب **تلغرام** (لإنشاء القناة الرسمية)
- الحاسوب: مطلوب **مرة واحدة فقط** لرفع الكود — ولا يلزم بقاؤه متصلًا بعدها

---

## 2) إنشاء حساب Zeabur (بلا بطاقة)

1. افتح <https://zeabur.com> ثم **Sign Up**.
2. لديك خياران:
   - **متابعة بحساب GitHub** (الأسهل: زر "Continue with GitHub")، أو
   - **البريد الإلكتروني**: اكتب بريدك ثم ضع كلمة مرور. **لن يطلب منك بطاقة بنكية** في الخطة المجانية.
3. بعد الدخول ستصل إلى **Console** (لوحة التحكم). أنشئ **Project** جديدًا باسم `mrw-bot`.

> ✅ **تأكيد:** حتى تاريخ كتابة هذا الدليل، صفحة خطط Zeabur الرسمية تنص صراحة على أن
> الخطة المجانية لا تتطلب بطاقة ائتمان، ولم يُنشر أي إشعار رسمي بخصوص إنهاء الخدمة.

---

## 3) رفع الكود إلى GitHub (مستودع خاص)

من مجلد المشروع على جهازك (PowerShell):

```powershell
git init
git add .
git commit -m "نظام استقبال بلاغات المخالفات العسكرية"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/mrw-bot.git
git push -u origin main
```

> **الأمان مضمون:** ملف `.gitignore` المرفق يستثني `data/` و`media/` و`logs/` و`.env`
> و`*.session` — أي لا يُرفع أي توكن ولا صورة بلاغ ولا قاعدة بيانات.

بعد الدفع: من <https://github.com/new> أنشئ مستودعًا **Private** باسم `mrw-bot` (بدون README) ثم نفّذ الأوامر أعلاه.

---

## 4) ربط GitHub بـ Zeabur

1. من Zeabur: **Console → Settings → Integrations** ← **Link GitHub Account**.
2. التفويض: سيطلب منك GitHub تثبيت تطبيق **Zeabur** — اختر **Only select repositories** ثم حدّد
   مستودع `mrw-bot` فقط (أو كل المستودعات الخاصة إن أردت).
3. ارجع إلى Zeabur: **Project → New Service → GitHub** ← اختر مستودع `mrw-bot`.
   (اختر الفرع `main`.)

> Zeabur يبني الصورة تلقائيًا عبر `Dockerfile` الموجود في جذر المشروع، ثم ينشر الخدمة.
> كل دفعة جديدة إلى GitHub تُطلق نشرًا تلقائيًا.

---

## 5) ضبط متغيرات البيئة (الأسرار)

منZeabur: افتح الخدمة ← تبويب **Variables** ← **Add Variable**:

| الاسم | القيمة | ملاحظة |
|---|---|---|
| `BOT_TOKEN` | توكن البوت من BotFather | **سرّي** |
| `ADMIN_IDS` | `1557513643` | معرّفات المشرفين |
| `ARCHIVE_CHAT_ID` | معرّف القناة الرسمية | انظر الخطوة 6 |
| `SAVE_MEDIA_LOCALLY` | `0` | في السحابة: نعتمد على `file_id` في تلغرام |
| `BACKUP_INTERVAL_MIN` | `30` | نسخة احتياطية كل 30 دقيقة |
| `KEEPALIVE_INTERVAL_SEC` | `300` | نبضة الإبقاء كل 5 دقائق |
| `LOCAL_UTC_OFFSET` | `3` | توقيت مكة والرياض وصنعاء |
| `KEEPALIVE_URL` | رابط الخدمة العام | يُضبط بعد إتمام الخطوة 6 |

> تُحقن المتغيرات تلقائيًا داخل الحاوية، وتُخزَّن مشفّرة في Zeabur.

---

## 6) القناة الرسمية ومعرّفها

1. في تلغرام: **New Channel** (قناة **Private**) باسم مثل: `أرشيف بلاغات المخالفات العسكرية`.
2. إعدادات القناة ← **Administrators** ← أضف `@blgh_bot` مشرفًا بصلاحية **Post Messages** و **Read Messages**.
3. انشر أي رسالة داخل القناة، ثم أرسل أمر `/chatid` إلى البوت — سيردّ بمعرّف المحادثة.
4. انسخ المعرّف (يبدأ بـ ‎-100‎) وضعه في المتغير `ARCHIVE_CHAT_ID`.

---

## 7) تفعيل الرابط العام وضبط نبضة الإبقاء

1. من Zeabur: افتح الخدمة ← تبويب **Networking / Domains** ← **Generate Domain** (أو اربط نطاقك الخاص).
2. احصل على رابط شبيه بـ: `https://mrw-bot-xxxx.zeabur.app`
3. أضف متغيرًا جديدًا في تبويب **Variables**:
   ```
   KEEPALIVE_URL = https://mrw-bot-xxxx.zeabur.app
   ```
4. أعد النشر (Redeploy) لالتقاط المتغير الجديد.

> بهذا لا تنام الخدمة المجانية أبدًا، لأن البوت نفسه يطلب رابطه كل 5 دقائق.

---

## 8) التشغيل والاختبار

1. من تبويب **Logs** تأكد من ظهور:
   - `✅ البوت جاهز ويستقبل الرسائل …`
   - `📁 القناة الرسمية جاهزة: …`
   - `بدأت نبضة الإبقاء نشطة كل 300 ثانية: …`
2. أرسل `/start` للبوت من حساب تجريبي ← صورة ← رابط ← وصف ← **إرسال**.
3. تأكد من وصول البلاغ:
   - في محادثة المشرف (إشعار فوري)،
   - في القناة الرسمية (منشور البلاغ)،
   - في لوحة `/admin`.
4. تأكد من النسخ الاحتياطي: ستظهر ملفات `.db` داخل القناة الرسمية كل 30 دقيقة.
5. **اختبار الاستمرارية:** أعد النشر (Redeploy) من Zeabur، ثم أرسل `/start` — يجب أن يستعيد
   البوت قاعدة البيانات تلقائيًا من القناة وتظهر البلاغات القديمة كما هي.

---

## 9) المراقب الخارجي (ضروري لمنع النوم التلقائي)

> ⚠️ **نقطة جوهرية:** النبضة داخل البوت (`KEEPALIVE_URL`) لا تنفع إذا أوقفت المنصة
> الحاوية نفسها، لأن البوت يكون متوقفًا ولا يستطيع أن يطلب شيئًا.
> لذلك نحتاج **مراقبًا خارجيًا** يطلب رابط الخدمة كل 10 دقائق، فيوقظها إن نامت.

الحل الجاهز في المشروع: `.github/workflows/keepalive.yml`

1. أنشئ مستودع GitHub (خاص أو عام) ودفع إليه الكود — فيعمل ملف المراقب تلقائيًا.
2. من المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**:

   | الاسم | القيمة |
   |---|---|
   | `SERVICE_URL` | `https://mrw-bot-xxxx.zeabur.app` |
   | `BOT_TOKEN` | توكن البوت (اختياري — لإرسال تنبيه عند التعطّل) |
   | `ADMIN_IDS` | `1557513643` (اختياري) |

3. من تبويب **Actions** شغّل سير العمل `keepalive` يدويًا (**Run workflow**) للاختبار.

**التكلفة:** مستودع عام = دقائق بلا حد، وخاص ≈ 1440 دقيقة شهريًا (ضمن 2000 المجانية).

## 10) حدود الخطة المجانية وماذا لو توقفت

- الخطة المجانية: خدمة واحدة، بناء بـ 2C4G، سجلات 48 ساعة. **بلا بطاقة بنكية.**
- الخدمة تنام تلقائيًا عند الخمول → **منعنا ذلك بالمراقب الخارجي** (كل 10 دقائق).
- إن نامت الخادم لأي سبب: الرسائل تبقى في طابور تلغرام وتُسلَّم فور الاستيقاظ،
  وقاعدة البيانات تُستعاد من القناة الرسمية تلقائيًا.
